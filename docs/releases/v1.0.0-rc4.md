# ContextOS v1.0.0-rc4

RC4 extends the RC3 local memory runtime with native text adapters for OpenAI Responses, Anthropic Messages, and Gemini Interactions, plus named OpenAI-compatible endpoints. One ContextOS memory store supplies retrieval and compiled context to every provider. `contextos ask` and `contextos models providers` add a direct CLI request path and safe provider status.

Remote providers are disabled by default. An explicit remote `--provider` request sends the compiled context selected for that request to that provider. Automatic cloud fallback requires both `--allow-fallback` and `--allow-remote`. Credentials are read from named environment variables at request time and are not stored in config, SQLite, telemetry, or release artifacts. Provider errors expose fixed safe diagnostics.

OpenAI, Anthropic, and Gemini adapters are protocol contract tested with mocked HTTP. Live validation of each is reported separately; no live claim is made from mocks. Ollama regression and clean package smoke are release gates. Answer quality is **NOT VALIDATED**. Synthetic ranking and token reduction are not provider billing evidence. Graph augmentation remains opt-in. Other platforms, models, and provider combinations are not comprehensively tested.

The release report records exact tests, review findings, live validation status, tag, and artifact hashes after all gates finish. See [provider setup](../providers.md) and the [API plan](v1.0.0-rc4-plan.md).
