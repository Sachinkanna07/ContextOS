# ContextOS v1.0.0-rc3

Release candidate dated October 3, 2026. Distribution version: `1.0.0rc3`.
Install with `pip install contextos-memory-runtime==1.0.0rc3` once published.
Imports, CLI and MCP CLI remain `contextos`, `contextos` and `contextos-mcp`.
RC2's published source, tag and artifacts remain immutable.

## Repairs

- Stats and monitor always send a period and include model/provider filters only
  when supplied. Empty and whitespace-only filters are rejected by the CLI and
  dashboard API. Unfiltered activity no longer requires explicit filters.
- Dashboard and model listing share bounded concurrent discovery. Each provider
  has a five-second discovery budget, a ten-second successful inventory cache,
  and a one-second failed/empty inventory cache. Concurrent refreshes coalesce;
  provider replacement invalidates its inventory. Failed providers do not hide
  healthy providers, expose raw errors, or retain stale available models.
- Inventory adapters make one request rather than probing health first. Failed
  cached health checks no longer freeze discovery. Empty/unavailable endpoints
  do not fabricate a default model. Fake models remain marked simulated.
- Ollama error diagnostics expose only recognized runtime facts and bounded exit
  codes. Arbitrary provider error text, credentials, paths and terminal controls
  are excluded. Malformed response shapes and token counts raise typed errors.
  Provider-reported zero usage is preserved; absent usage approximates all
  dispatched message content using the selected tokenizer basis.

## Actual investigation and live evidence

RC2 stats serialized absent values as `model=&provider=&period=all`. The dashboard
then filtered for empty identifiers. RC2's Ollama inventory took 2.443 seconds on
this host while the dashboard's one-second deadline discarded it. Isolated HTTP
client construction took approximately 1.1–1.6 seconds before network I/O;
Ollama `/api/tags` itself responded in milliseconds. The five-second budget was
chosen against measured setup and adapter behavior and tested with a healthy
provider taking over one second, dead/timeout/fast/mixed providers, cache expiry,
failure recovery, concurrent refreshes and a bounded dashboard response.

Ollama 0.34.0 listed `qwen2.5-coder:14b`, `qwen3.5:9b` and
`qwen2.5-coder:7b`. A minimal raw Qwen3.5 `/api/chat` request outside ContextOS
returned HTTP 500. Its JSON error and local server log established a model runner
failure: **CUDA shared object initialization failed**, exit **`0xc0000409`**.
This is an intermittent external runtime failure, not evidence of incompatible
ContextOS messages, temperature, context formatting or `num_predict` semantics.
A subsequent ContextOS-shaped raw request returned HTTP 200 but spent its
256-token budget on thinking and had empty final content with `done_reason=length`.
The adapter preserves that valid done response and excludes private thinking.
No Qwen3.5 string workaround, automatic retry, forced CPU mode, changed thinking
setting or provider request semantics were introduced.

A later real ContextOS daemon run remembered four test preferences/project facts
and completed memory-aware requests using both discovered models:

| Model | Dispatch | Provider input/output/total tokens | Result |
| --- | --- | --- | --- |
| `qwen2.5-coder:7b` | `RESPONSE_RECEIVED` | 79 / 30 / 109 | Named ContextOS, Java and local-first tools |
| `qwen3.5:9b` | `RESPONSE_RECEIVED` | 82 / 473 / 555 | Named the stored project, language and tools |

Both had compiled context, matching dispatch evidence, persisted success
telemetry, provider-reported usage and retrieval/compilation/provider latency.
Unfiltered and filtered stats, one-sample monitor, model listing, doctor and clean
daemon stop were exercised. Qwen3.5 took approximately 132 seconds end to end in
that run with an explicitly requested 150-second timeout; broad reliability or
default-timeout compatibility is not claimed.

Candidate context was 63 approximated tokens and compiled context 78. Measured
reduction was **0%**; tiny-context formatting overhead can exceed source content.
This invocation establishes no provider-billed savings or answer-quality claim.

## Verification scope

Two consecutive final-source full runs each passed **760 tests**, with **0 failed**
and **0 skipped** (399.78 seconds and 363.89 seconds). This includes 51 new RC3
regression cases in addition to RC2's 709 tests.
Full validation includes compileall, complete pytest runs, archive validation,
Twine checks, clean wheel installation, daemon smoke checks, dependency checks,
fresh review and clean-checkout verification. The release report records final
gate outcomes, exact commit/tag, canonical artifact byte sizes and SHA256 hashes.
Publication is complete only after TestPyPI and production identity/smoke gates.

Untouched RC2 had 910 Ruff findings and 147 strict Mypy diagnostics with the
installed tools. RC3 has 906 and 146 respectively, with no new diagnostics.
The new discovery service, Ollama adapter and RC3 test file pass targeted Ruff;
discovery and Ollama pass targeted strict Mypy. Repository-wide checks remain
nonzero due to inherited development-tooling debt; configuration was not relaxed.
The host's global environment also has an unrelated Streamlit/packaging conflict;
dependency-isolated package checks are the release installation gate.

## Known limitations

- Answer quality is **NOT VALIDATED**. Spot-checking these responses does not
  establish general answer accuracy or quality.
- Graph augmentation remains opt-in because measured synthetic ranking and
  latency tradeoffs exist.
- Synthetic token reduction is not provider-billed savings.
- Live providers/services/models have not been comprehensively validated.
  Qwen3.5's intermittent CUDA initialization failure remains external.
- Deterministic embeddings and token approximation are the lightweight defaults;
  SentenceTransformers is optional and explicitly selected.
- Python 3.12 is declared supported. Complete validation on this host uses
  Windows 11 and Python 3.13.5; other platform/version coverage is not claimed.
