that every production deployment or provider has been penetration-tested. The
referenced tests are reused rather than duplicated. Run the listed test modules
with `python -m pytest ... -q`.

## Explicit limits

- The repository tests deterministic application-level SQLite cancellation and
  contention, but do not constitute a multi-process lock-duration or power-loss
  chaos campaign.
- Windows 11 / Python 3.13 is the validated runtime here. UNC/device path
  rejection is tested using path-shaped inputs; no network share is required.
- No live provider, production credential, external MCP host, or real user data
  is used by these tests.
- Benchmark answer quality and real-world secret-recognition recall are not
  measured by this matrix.
